# NGC1044-MeerKAT-data-products
Repository containing image products from Clews et al. (2026)  'A MeerKAT spectropolarimetric investigation of the tailed FRI radio galaxy NGC 1044'.

Data products that are included:
- S-band full intensity (Stokes I) images at 3 resolutions: 7,12 and 20 arcseconds (e.g. S_12arc-StokesI-MFS-image.fits)
- Primary beam corrected S-band full intensity (Stokes I) images at 3 resolutions: 7,12 and 20 arcseconds (e.g. S_12arc-StokesI-MFS-image-pb.fits)
- L-band full intensity (Stokes I) images at 3 resolutions: 7,12 and 20 arcseconds (e.g. L_12arc-StokesI-MFS-image.fits)
- Primary beam corrected  L-band full intensity (Stokes I) images at 3 resolutions: 7,12 and 20 arcseconds (e.g. L_12arc-StokesI-MFS-image-pb.fits)
- L to S band spectral index maps at 3 resolutions: 7,12 and 20 arcseconds (e.g. NGC1044_SpectralIndex_12arc.fits)
- L to S band spectral ageing maps for the JP model at 3 different resolutions: 7,12 and 20 arcseconds (e.g. NGC1044_SpectralAgeing_12arc_JP_B7.94e-10.fits) 
- L to S band spectral ageing error maps for the JP model at 3 different resolutions: 7,12 and 20 arcseconds (e.g. NGC1044_SpecAgeErrorMap_JP_12arc_B7.94e-10.fits)
- L to S band spectral ageing maps for the KP model at 3 different resolutions: 7,12 and 20 arcseconds (e.g. NGC1044_SpectralAgeing_12arc_KP_B7.94e-10.fits)
- L to S band spectral ageing error maps for the KP model at 3 different resolutions: 7,12 and 20 arcseconds (e.g. NGC1044_SpecAgeErrorMap_12arc_KP_B7.94e-10.fits)
- NGC1044_RMSynth_peakRM.fits: Peak Faraday rotation measure (RM) map.
- NGC1044_RMSynth_FDF_maxPI.fits: A map of the maximum polarized intensity in each Faraday dispersion function (FDF, i.e. for each pixel).
- NGC1044_RMSynth_peak_fit_dPhiPeakPIfit_rm2.fits: Fitting error in peak Faraday depth.
- NGC1044_peak_fitdFDFcorMAD.fits: Estimated noise in the Faraday depth spectrum, computed using the median deviation from the median (MADFM) of polarized intensity in the spectrum, and then correcting to be equivalent to a Gaussian sigma.



Data products that are not included here due to file size restrictions, but are available on request to the author:
- Measurement sets
- Stokes I, Q, and U cubes
- RMSF cube
- Dirty FDF cube
- clean FDF cube
